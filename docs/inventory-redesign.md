# 独立库存工作台

用户已确认账号池、卡密管理、单个充值、批量充值、充值记录五页分离。账号不绑定库存卡密，发起充值才为所选账号分配同规格未使用卡密。开始前确认一次，之后自动获取 Session、预检、提交与查询。

## 当前审查

旧界面深色、紫色强调、Segoe UI/微软雅黑，字号大多为 10–13px，所有导航共享同一账号卡密表，预检、说明和动态挤占每页空间。保留原生 Edge 登录、扩展接续、单行 Session 查看复制、任务日志与提交防重。拆除共享大表、重复操作入口和各页固定流程说明。

## 视觉

管理工具使用官方 Fluent UI React 和 TanStack Table，使用本机 Segoe UI/微软雅黑。DESIGN_VARIANCE=3，MOTION_INTENSITY=2，VISUAL_DENSITY=4。中性底色、低饱和绿色强调，正文 16px、表格 15–16px，统一 8px 圆角。主题由根级 FluentProvider 统一切换，默认跟随系统。桌面侧栏五个页面；窄屏切换为紧凑导航。每页只呈现自身数据，详情放在对话框。无营销 hero、装饰图片、滚动动画或虚构统计。

## 数据和约束

独立账号、卡密和充值任务。卡密规格为 plus、pro100、pro200、pro500。账号邮箱和卡密值各自去重，列表使用稳定序号。旧关联记录拆为库存与历史任务，保留关联；Session 不落盘。账号历史充值结果与实际套餐分开展示。

库存分配在本地事务中校验账号锁、卡密锁、规格和数量。确认前展示明确的分配预览；确认时若库存变化，则要求重新选择。结果未知的卡密保持占用，成功标使用，只有确定可释放才回库。仅获取 Session 不调用兑换服务。Plus 和半价 Plus 是不同 SKU，必须与上游 `plus` / `plus_half` 资格严格匹配。Pro 可导入与管理，但 Pro 实际兑换未启用。

## 验证

验证旧数据迁移、去重、四类库存、批次导入原子性、同类分配、并发占用、库存不足、预览失效、成功/未知/失败释放、重复提交保护和重启恢复。实际浏览器检查五页隔离、导入、搜索、筛选、分页、单次确认、单行 Session、大小屏与双主题。财务动作使用模拟服务测试；不消耗实际卡密。
