# v2.2.1：手机操作与灵活导入

用户已确认兼容 `--` 和 `//`，同时保留 `----`。账号每行支持邮箱、邮箱＋密码、邮箱＋密码＋2FA、完整四段；邮箱取码链接可缺省。每行根据邮箱后的分隔符识别，不用斜杠拆开 HTTPS 链接；密码中的普通单横杠、斜杠和特殊字符原样保存。同一行需使用相同分隔符；CSV/JSON 为字段本身包含分隔符时的明确输入方式。URL、邮箱和批量原子校验继续保留，错误只提示行号，不回显凭据。

普通账号每行提供直接移入风控入口，手机以逐条卡片形式显示，邮箱和操作按钮保持在同一条目中；风控页增加“添加风控账号”，允许只有邮箱或完整资料。新账号导入并移入，已存在的普通邮箱按本次明确选择移入，已在风控池的跳过，不覆盖已有密码配置。批次中的忙碌账号在任何写入前拒绝，防止部分移动；已提交状态和原卡密锁不变。

卡密可删除未使用或已使用条目；占用中、结果不明或正在核对的禁止。已使用卡密从库存列表隐藏，保留摘要、状态及任务关联以防重复导入回库，充值记录保留。未使用卡密保留原有删除语义。后端提供 deletable 和阻止原因，界面行操作和批量操作一致。

手机仍访问同一个电脑后端。前端刷新即可更新，接口变动需重启电脑服务；手机网关跟随固定运行元数据自动找到服务，地址和手机配对不变。本次更新静态资源不缓存，验证电脑与真实 Tailscale HTTPS 的手机页面、输入、风控移动和删除均使用隔离合成数据。升级保留当前数据与内存 Session，不擅自导入用户消息中的真实账号或删除真实卡密。

缺少接码链接不影响保存账号或使用本地 2FA；如果登录流程要求邮箱验证码，仍需补充取码链接或在浏览器中手动输入验证码。密码本身含有所选分隔符或短横线空字段产生歧义时，使用 CSV / JSON 明确字段。
