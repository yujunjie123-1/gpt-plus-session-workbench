# Session 文件提取页（v2.3.3）

## 功能

左侧“Session 提取”页面支持选择或拖放单个 `.docx` / `.txt` 文件。首版按每个文件只有一个 Session 设计，页面提取后显示邮箱和账号池相同的紧凑单行 JSON，并提供一键复制。

## 解析规则

文件中必须存在一个 JSON 对象，并同时包含 `user.email`、非空 `accessToken`、非空 `sessionToken` 和 `expires`。TXT 优先 UTF-8（含 BOM），失败时回退 GB18030；DOCX 使用标准库读取正文和表格文字。旧版二进制 `.doc` 不支持。

没有匹配对象、JSON 损坏、超过 10 MiB、DOCX 损坏或发现多个 Session 时会明确报错，不自动猜测或选择。提取只做格式识别，不调用 GPT 或兑换服务验证，因此不能把“已提取”理解为“当前有效”。

## 数据边界

文件通过受本机授权保护的接口上传到本机后端，在进程内存中解析后立即返回结果。文件和 Session 不写入数据库、日志、升级文件、导出文件或临时文件；清除结果、关闭页面或后台重启后不保留提取内容。手机入口仅通过已配对的网关转发该二进制请求。

## 验证

使用合成 Session 覆盖 UTF-8 / GB18030 TXT、DOCX 段落、DOCX 表格、无匹配、非法格式、多对象、空文件和大小上限。浏览器验证覆盖文件选择、拖放、紧凑复制、清除结果、旧版 `.doc` 拒绝，以及卡密和充值页面半价 Plus 排在普通 Plus 前。未使用真实 Session 或真实卡密。

提取成功后可以在同一页输入单张卡密，选择半价 Plus 或 Plus，执行 Partner API 预检并确认直充。直充只写独立充值历史，不创建账号池账号；Session 仅在本次后台内存任务中使用。
