# v2.2.2：Session 独立并发与浏览器启动

用户确认默认同时获取 5 个账号的 Session。账号池和风控池显示独立的 1–10 并发选择，不再受批量充值默认并发 1 影响；设置写入现有本机数据库，重启保留。暂停仍对所有本地队列生效，降低并发不取消已运行任务。超过所设数量才排队，一个账号等待验证码时不会阻塞其他可用槽位。充值库存锁和登录实例授权保持原有规则。

慢启动的原因是每个账号从零启动后台 Edge，加载助手、开启 InPrivate 权限，再结束准备进程，最后启动真正的无痕登录。改为在工作台启动后后台准备一次从未登录的空白模板，按 Edge 版本及助手文件内容失效更新。每次任务复制到新的唯一目录后启动独立原生 InPrivate 窗口，登录后的目录仍在结束时删除，绝不把账号登录目录回写成模板。实际 GPT 登录保持不接 DevTools。模板创建期间可等待；模板已就绪后不再逐次启动后台准备浏览器。

验证必须覆盖5 个真实独立原生窗口与同源 Cookie/localStorage 隔离、默认 5 并发且充值并发为 1、并发设置持久化、暂停/限流/失败释放、取消准备不晚开窗口、冷启动/模板复用耗时。使用本地合成页面，不执行真实账号登录或充值。升级读取当前数据和 Session 动态数量，备份后接续原服务与手机入口。
