# 账号池一键复制（v2.2.3）

用户要求将账号资料“一键复制”加入普通账号池，未充值账号也可使用。每行操作区增加按钮，全部、未充值、已充值、Session 就绪以及资格筛选下均可使用；不依赖 Session 或充值结果。

复制格式为四行：邮箱账号、GPT密码、2FA密钥、在线获取2FA网站 https://2fa.vip/index.html。缺少密码或密钥时对应值为“未配置”。不包含邮箱接码链接、Session 或卡密。

点击时才调用受现有本机授权 / Origin 校验保护的 POST /api/inventory/copy-account，从 DPAPI 解密保存的资料；不写历史、不改库存或任务，不向轮询状态附加敏感字段。手机入口仅对已配对用户允许该接口，既有 HTTPS、Cookie 与 Origin 校验继续生效。

点击后先建立本次复制的剪贴板写入，再读取本机资料，避免首次点击因等待接口而丢失浏览器授权；复制过程中只标记当前行，账号资料与 Session 不会互相覆盖。剪贴板成功时显示成功提示；浏览器拒绝时打开只读文本框，支持再点击复制或选中文本手动复制。关闭弹窗清空展示状态。账号不存在或读取失败时显示错误，不提示复制成功。

验证使用独立临时数据库和合成账号，覆盖未充值与成功历史账号、缺字段、手机布局、剪贴板限制、接口权限、无任务 / 卡密副作用以及状态和持久化数据不包含复制明文。测试剪贴板为页面内模拟对象，不覆盖用户系统剪贴板。
