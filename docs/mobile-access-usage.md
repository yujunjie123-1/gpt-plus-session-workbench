# 出门后使用手机工作台

电脑和手机安装 Tailscale，加入相同私有网络。电脑保持开机、联网、不自动睡眠。

## 首次连接

1. 电脑正常启动充值工作台，再双击同目录“启动手机访问.cmd”，保留后台进程。
2. 电脑手机连接设置页显示专用 HTTPS 地址；在手机保持 Tailscale 已连接，用 Chrome 打开该地址。
3. 电脑点击“生成 10 分钟配对码”；手机输入 8 位码。代码一次有效，过期可重新生成。
4. 手机授权保留 30 天。电脑点“退出全部手机”可撤销已有授权；手机刷新后重新配对。

本机固定手机地址为 https://laptop-0gi885lj.tail118d62.ts.net 。其他电脑需以设置页显示的本机地址为准。这个地址仅供当前 Tailscale 私有网络访问，不使用公网 Funnel。

## Tailscale 首次设置

本机入口转发配置命令为 `"C:\Program Files\Tailscale\tailscale.exe" serve --bg --https=443 http://127.0.0.1:51931`。只有首次或更换电脑时需要配置。若提示 Serve 未启用，需账号所有者打开命令提供的 Tailscale 控制台链接启用 Serve／HTTPS，再运行一次此命令。

Serve 在 Tailscale 中保存配置，电脑重新启动后仍需启动工作台和手机网关。原工作台端口即使改变，手机网关也会读取本机运行信息自动找到新服务。

## 使用边界

手机负责查看和发起任务，Edge 登录窗口、验证码获取、Session 和充值继续在电脑运行。遇到人机验证时，需要电脑操作或通过另外配置的远程桌面接管。连接页和工作台已检查 390px 手机布局；手机端逐条展示账号与操作按钮，无需横向拖动表格。

工作台、数据库和账号资料留在本机。Tailscale 负责加密传输，无法直连时可能使用加密中继。HTTPS 由 Tailscale Serve 终止；浏览器中所有账号操作仍需先完成工作台配对。

本次手机接入不包含此前另外提出的“成功账号交付资料复制”和“充值按 1/3 个月资格下拉筛选”；这两项需求仍待独立开发。
