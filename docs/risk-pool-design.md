# 风控账号池（2026-11-07）

用户已确认：明确银行卡拒付或 approve 未允许时自动移入风控池；单个及批量充值仅选择从未充值成功、不在风控池的账号；养号后手动移回，不按天数自动恢复。

账号持久保存独立的 risk 对象：是否隔离、固定原因代码、脱敏说明、进入时间、恢复时间和操作历史。普通账号池隐藏被隔离账号；左侧新增风控账号池，支持搜索、查看原因和养号时间、查看账号详情、单个或批量移回。Session 获取仍可用于检查账号，充值必须先移回。

后端在分配预览、实际占用库存、启动任务、预检与提交时检查风控和历史成功记录。成功历史按邮箱查询，删除再导入同邮箱也不能变成未充值账号。预览后账号状态变化必须拒绝启动，不占用卡密。前端轮询时移除失效选项和批量选择，充值过程中保留当前任务进度。

只从已知错误代码和错误字段识别两类明确失败，不持久保存上游原始响应。拒付、approve 不允许属于用户指定的暂缓规则，不意味着已证明是账号本身的风险。普通失败、权限错误、超时、卡密过期、已有套餐不自动隔离。预检拒绝未提交时按原规则释放可释放卡密；提交后结果不明仍保持占用，仅查询原任务。移回普通池不会解除未核实充值的锁，也不会自动重试或提交。

测试先覆盖错误识别及排除、预检/提交/查询路径、单个和批量过滤、过期预览、历史成功、恢复、重启持久化及原有兑换防重，再构建并用实际浏览器测试。所有兑换测试使用合成账号和模拟服务。

实施顺序：实现错误分类与账号策略；接入库存和兑换流程；增加独立风控界面；补充业务及浏览器检查；备份后升级本机两份代码并打包。浏览器隔离本次完成官方文档调查，不直接切换现有真实登录路径。

浏览器调查：Chrome 官方说明新无痕窗口延续同一无痕会话；Edge 官方支持通过 --user-data-dir 指定用户目录。独立目录加无痕窗口适合保留原生 Edge 登录，但各目录需要独立配置扩展与 InPrivate 权限。WebView2 官方支持 ProfileName 与 IsInPrivateModeEnabled，适合后续嵌入式方案，其真实 GPT 登录与扩展替代仍需另外验证。不能据此承诺消除登录 400 或支付限制。
