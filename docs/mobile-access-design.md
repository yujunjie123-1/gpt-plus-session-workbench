# 手机通过 Tailscale 访问本机工作台

用户已完成电脑和手机加入同一 Tailscale，并要求继续连接。采用此前推荐的 Tailscale 私有 HTTPS 接入，不使用 Funnel、公网监听或路由器端口映射。

增加独立本机网关，绑定 127.0.0.1:51931。Tailscale Serve 将本设备专用 HTTPS 地址转发到网关。原充值服务保持仅监听 loopback，不改变原服务 Host、Origin、助手及授权规则，不重启原服务或丢失 Session。

手机第一次访问显示配对页，在电脑本地设置页取得 8 位一次性配对码；十分钟有效，使用后作废，有失败尝试限制。成功后使用 Secure、HttpOnly、SameSite=Strict Cookie，30 天有效。签名密钥和手机网关设置使用当前 Windows 用户 DPAPI 保存。远程请求核对专用 Host、同源 Origin 和认证 Cookie；设置页面仅能从本机的独立管理入口访问。重新生成授权密钥可撤销已有手机。

网关仅转发工作台管理所需接口、页面与静态资源，使用原服务运行元数据在本机取得授权，不向手机交出桌面启动口令。禁止手机访问助手连接、实例交接和服务关闭接口。网关自动读取运行端口变化，因此关闭再启动工作台无需重新配置 Tailscale。

提供电脑端设置页：显示固定手机地址、连接状态、生成配对码和退出全部手机。手机页面沿用现有响应式界面。本次不把复制交付资料及资格筛选需求混入网络接入；这些需求已拆解，尚未在此步骤实现。

验收包括拒绝未配对、错误 Host/Origin、失效配对码、登录限流和内部接口；正确配对可通过网关访问模拟后端并执行正常操作。真实本机页面验证不提交真实登录、预检或兑换，不打印账号资料和 Session。Tailscale HTTPS 若需控制台启用，保留已完成的接入并给出具体启用页面；不把等待授权称为已连接成功。
